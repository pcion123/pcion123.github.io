Grafana + Prometheus + Node Exporter 安裝與監控 Dashboard 建置

發表於 2026-07-30 更新於 2026-08-02 分類於 grafana

這篇文章記錄如何在 Linux 環境中安裝 Prometheus、Grafana 與 Node Exporter，並透過 Grafana 匯入 Node Exporter Dashboard，建立一套基本的主機監控環境。

整體流程會先完成 Prometheus 的服務安裝，再安裝 Grafana 作為視覺化介面，接著部署 Node Exporter 讓 Prometheus 能夠收集主機 Metrics，最後在 Grafana 中設定資料來源並匯入 Dashboard。

安裝 prometheus

首先建立 Prometheus 專用的系統使用者，並準備設定檔與資料儲存目錄。這個使用者不需要登入系統，也不需要家目錄，主要用途是讓 Prometheus 服務能以獨立權限執行。

接著從 Prometheus 官方 GitHub Release 下載 Linux AMD64 版本，並解壓縮安裝檔。

解壓縮完成後，將 Prometheus 與 promtool 執行檔複製到 /usr/local/bin/，再將預設設定檔放到 /etc/prometheus/ 底下，並設定檔案擁有者。

接著建立 Prometheus 的 systemd service，讓 Prometheus 可以透過 systemctl 管理。

建立服務檔後，重新載入 systemd 設定，啟動 Prometheus 並設定開機自動啟動。

服務啟動後，開啟瀏覽器進入 http://127.0.0.1:9090，確認 Prometheus 是否正常運作。

安裝 grafana

Prometheus 負責收集與儲存監控資料，而 Grafana 則用來建立視覺化 Dashboard。這裡使用 Grafana 官方提供的 .deb 套件進行安裝。

Grafana 下載頁面通常會提供 Enterprise 與 OSS 兩種版本。OSS 是開源版本，已包含建立 Dashboard、設定資料來源、查詢 Prometheus 與基本告警等常用功能；Enterprise 則包含 OSS 的功能，並可在授權後啟用企業級功能與外掛，例如進階權限控管、企業資料來源外掛、報表與官方支援等。若只是建立本文這類 Prometheus 與 Node Exporter 的主機監控環境，使用 OSS 版本即可。

安裝完成後，修改 Grafana 設定檔 /etc/grafana/grafana.ini，讓 Grafana Server 綁定到 0.0.0.0，並使用預設的 3000 連接埠。

接著重新載入 systemd 設定，啟動 Grafana Server 並設定開機自動啟動。

開啟瀏覽器進入 http://127.0.0.1:3000，確認 Grafana 是否正常運作。

Grafana 預設帳號與密碼皆為 admin，首次登入後會要求重新設定密碼。

完成登入後，就可以進入 Grafana 主畫面。

安裝 node_exporter

Node Exporter 會提供主機 CPU、記憶體、磁碟、網路等系統 Metrics，讓 Prometheus 可以定期抓取並儲存。首先下載 Node Exporter 的 Linux AMD64 版本並解壓縮。

接著建立 Node Exporter 專用使用者。

將 Node Exporter 執行檔複製到 /usr/local/bin/，並設定擁有者。

建立 Node Exporter 的 systemd service。

接著回到 Prometheus 設定檔，新增 Node Exporter 的 scrape target，讓 Prometheus 可以抓取 localhost:9100 提供的 Metrics。

最後可以透過 curl 驗證 Node Exporter 是否正常輸出 Metrics。

接著下載 Node Exporter 的 Dashboard 樣版設定。這裡使用的是 Grafana Labs 上常見的 1860 樣板，也就是 Node Exporter Full。這個 Dashboard 主要搭配 Prometheus 與 Node Exporter 使用，可以直接呈現主機的 CPU、Memory、Disk、Filesystem、Network、Load Average 等系統監控資訊。

匯入時可以使用 Dashboard ID 1860，也可以從頁面下載 JSON 後再匯入。若前面已經完成 Prometheus datasource 設定，匯入時只要選擇對應的 Prometheus 資料來源，就能讓 Dashboard 讀取 Node Exporter 收集到的 metrics。
