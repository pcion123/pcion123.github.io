一個月 Kubernetes 挑戰後的回顧

發表於 2026-08-28 更新於 2026-09-02 分類於 mindset

這個月，我幾乎完成了一場類似 iThome 鐵人賽的自我挑戰。回頭看這段時間，雖然每天都要整理學習內容、實作環境、消化觀念，過程並不輕鬆，但也讓我更完整地理解 Kubernetes 在現代化 Server 部署中的角色與價值。

一開始設定這個系列時，我希望能透過一個月的時間，從 Kubernetes 的基礎概念一路走到更貼近實務的部署流程。原本規劃的目標其實更大，除了基本的 Kubernetes 部署之外，也希望能延伸到 Helm、Argo CD，甚至是真的把環境跑在 GKE 上，讓整個流程更接近實際工作中的雲端部署情境。

不過，實際執行後才發現，一個月的時間要把這些內容都完整消化並整理成文章，確實比想像中更有挑戰。礙於時間與精力的限制，最後沒有辦法把 Helm、Argo CD 與 GKE 實作都納入這次系列中，這算是比較可惜的地方。

即便如此，這次最基本也最核心的目標，也就是完成「Webchat Kubernetes 完整部署 Demo」，還是有順利達成。從應用程式部署、服務暴露，到逐步理解 Kubernetes 中各種資源的用途，這段過程讓我不只是看懂指令或設定檔，而是更清楚知道每個元件在部署架構中扮演的角色。

至於這個 Demo 的源代碼，因為整個實作過程其實相當凌亂，裡面還有不少需要整理與調整的地方，所以目前暫時不會立刻放到 GitHub 上。等之後有空把專案結構、設定檔與說明文件都整理好，再考慮把完整內容分享出來。現在的我只想先好好休息一下，讓這段密集學習的節奏先告一段落。

這整個月算是過得相當充實。每天都在學習、實作、整理筆記與回顧問題，雖然常常會遇到卡關的時候，但也因為這樣，才真正感受到 Kubernetes 並不是單靠閱讀文件就能掌握的技術。它需要不斷動手操作，從錯誤中慢慢建立理解，才能把抽象的概念轉化成具體的經驗。

除了技術上的學習，這段時間對我來說也有另一層意義。因為當時是裸辭在家，心裡其實承受了不小的壓力。一方面想把這個學習系列完成，另一方面也必須面對求職與未來方向的不確定感。還好最後也順利上岸，讓這段時間的努力有了一個相對穩定的落點。

當然，上岸不代表挑戰就結束了。接下來還會有新的工作內容、新的技術需求，也會有更多需要適應與突破的地方。但經過這個月的訓練，我也更相信自己有能力面對這些挑戰。至少我已經證明，只要願意持續投入，即使一開始不熟悉，也能一步一步把複雜的東西拆開、理解，最後完成一個具體的成果。

接下來，文章更新應該不會像這個月一樣頻繁。這段時間密集輸出的節奏確實很有收穫，但也需要回到比較穩定、能長期維持的狀態。不過，如果之後遇到有興趣的主題，或是在工作與學習中累積到值得記錄的內容，還是會繼續寫下來。

這次 Kubernetes 系列對我來說，不只是一次技術學習，也是一段重新整理自己狀態的過程。雖然原本規劃的目標沒有百分之百完成，但能在有限時間內完成 Webchat Kubernetes 完整部署 Demo，並且把這個月踏實走過的內容留下來，我覺得已經是很有意義的成果。

補充：後來已經把 Webchat Demo 的原始碼專案整理出來，並放到 GitHub 上。如果想對照文章中的 Kubernetes 部署流程與實際實作，可以參考：pcion123/webchat。
